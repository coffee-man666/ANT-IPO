## 4. 投票权细则（Voting Rights，L18074–18119）

**F014** Class A：每股 1 票，及于提交股东会表决的所有一般事项，**包括选举除 Class T 董事以外的董事**（L18075–18081）。

**F015** Class N：对提交股东会的任何事项均无投票权，**法律另有要求除外**——例如对公司注册证书某些会在不利影响 Class N 而未同样不利影响 Class A 的修正，DGCL 赋予 Class N 作为系列单独投票的权利（L18083–18088）。

**F016** Class T：除章程中关于选举董事会多数席位、赎回 Class E、对 Class F 权利的特定修订的规定，以及法律要求（如 DGCL 下作为单独类别对不利修正投票）外，对提交股东会事项无投票权（L18090–18097）。

**F017** Class F：有权就提交股东会表决的一般事项（含选举非 Class T 董事）投出**合计等于登记日流通股本总投票权 50.1%** 的票数；Class F 按 Founder LLC Agreement 规定的方式投票（L18099–18105，原文："The holder of our Class F common stock will be entitled to an aggregate number of votes that equals 50.1% of the total voting power of our outstanding shares of capital stock as of the applicable record date on matters submitted to a vote of stockholders generally"）。

**F018** Class E：除章程中关于 Specified Class T Director 的提名/罢免/变更指定（在 NGC 不认可 LTBT 行为的情形）、LTBT/Class T 条款的特定变更、Class T 的赎回，及法律要求外，无投票权（L18109–18119）。

## 5. 转换与可转让性细则（Conversion and Transferability，L18120–18160）

**F019** Class A：不可转换为其他类别股；在遵守法律及「Shares Eligible for Future Sale—Lock-Up and Market Standoff Agreements」限制的前提下可转让（L18121–18126）。

**F020** Class N 持有人主要是战略业务伙伴（"primarily strategic business partners"）；Class N 股份在**通过以下方式转让时自动转换为同等数量的 Class A**：(i) 注册发行或公开市场出售；或 (ii) 向第三方转让——该第三方 (A) 非 Class N 持有人（或其关联人），且 (B) 转让后将不会实益拥有或控制公司任何类别/系列股权证券的 **9.99% 以上**（L18128–18140）。

**F021** Class T：不可转换；仅在构成 Trust Amendment Threshold 的人士批准后方可转让；由于该等人士有权完全修改或终止 LTBT 及 Class T 权利，故对 Class T 受让人身份无单独限制（L18142–18149）。

**F022** Class F：不可转换；除经董事会批准且不改变 Founder LLC 成员的 Founder LLC 重组或迁址外不可转让（L18151–18156）。

**F023** Class E：不可转换为其他类别股，且不可转让（L18158–18160）。

## 6. 赎回（Redemption，L18161–18220）

**F024** Class A 与 Class N：公司或持有人均无可选择赎回权（"will not be redeemable at our option or at the option of the holder"）（L18163–18169）。

**F025** Class T 赎回（无偿）路径一：**若受托人（Trustees）投票赞成赎回**——需经董事会授权成员的 **80%** 与在任受托人的 **80%** 批准（各自按四舍五入取整，恰为 0.5 时向上取整）（L18172–18176）。

**F026** Class T 赎回路径二（Class F 仍流通且受托人不赞成）：
- **直至本次发行完成三周年**：需 (i) Class F 依 Continuing Founders **一致同意（unanimous approval）** 行动、(ii) Class E 投出票数的**过半数**（法定人数为流通 Class E 的 **40%**）、(iii) 流通 Class A 投出票数的**过半数**（法定人数为流通 Class A 的过半数）批准（L18183–18188）；
- **任何时间**：需 (i) Class F 经 **66 2/3%** 的 Continuing Founders 决定（向上取整）、(ii) Class E 投出票数的 **75%**（法定人数为流通 Class E 的过半数）、(iii) Class A 投出票数的过半数（法定人数为流通 Class A 的过半数）批准（L18190–18194）。

**F027** Class T 赎回路径三（无 Class F 流通且受托人不赞成）：需流通 Class A 股份的 **85%** 批准（L18196–18197）。

**F028** Class F 无偿赎回触发：(i) Founder LLC 经 Continuing Founders **Supermajority** 批准选择赎回；(ii) Founder LLC 解散；或 (iii) **Class F Transition Period 届满**——该期间自 Continuing Founders 少于三人（不含作为「Non-Qualifying Member」的继任成员）持续 **90 个连续日历日**时起算（L18199–18206）。

**F029** Class E：持有人无选择赎回权。员工**非因故（other than for cause）离职**时，其当时流通 Class E 股份的**一半**将被公司无偿自动赎回，**每年**（annually）执行一次（L18208–18212）。

**F030** Class E 全部无偿自动赎回触发：(a) 员工死亡、丧失行为能力、因故终止、或**开始为直接竞争对手服务**（commencement of service with a direct competitor）；(b) 不再有 Class F 流通时；或 (c) 经 (A) 董事会授权成员 80%（含 0.5 向上取整规则）、(B) Class F 持有人、(C) Class T 持有人批准（L18212–18220）。

## 7. 股息、清算与其他权利（L18221–18245）

**F031** 股息权：在优先股（如流通）优先权之下，Class A 与 Class N 持有人有权在董事会酌情决定时从合法可用资金中获得股息；**Class T、Class F、Class E 无股息权**（L18221–18228）。

**F032** 无优先认购权：普通股不享有优先认购权（preemptive rights），不受赎回或偿债基金条款约束（Class T/F/E 上述无偿赎回除外）（L18229–18232）。

**F034** 本次发行中发行的 Class A 股份，公司将由法律顾问出具**缴足且不可评估（fully paid and non-assessable）**意见（L18243–18245）。

## 8. 日落条款（Sunset Provisions，L18246–18469）

### 8.1 触发条件

**F035** **Class T Sunset Time**：当不再有 Class T 流通时发生——包括因赎回或通过消除 Class T 的权利修订实现，两者均需构成 **Trust Amendment Threshold** 的人士批准；满足路径与 Class T 赎回路径完全相同（80%/80%；或三周年前一致同意+Class E 过半数(法定人数40%)+Class A 过半数；或 66 2/3% Continuing Founders+75% Class E+Class A 过半数；或无 Class F 时 85% Class A）（L18250–18293、L18346–18351）。

**F036** Class T Sunset **不因时间流逝或特定事件而自动发生**，任何导致其发生的行动均需 Trust Amendment Threshold 批准；一旦触发，**不得延长、推迟或豁免**（not subject to extension, delay or waiver）（L18352–18359）。

**F037** **Class F Sunset Time**：以下两者中较早者：(i) 不再有 Class F 流通（包括经 Continuing Founders Supermajority 同意的赎回或 Founder LLC 解散）；(ii) **Class F Transition Period 届满**（该期间自 Continuing Founders 少于三人（不含 Non-Qualifying Member 继任成员）持续 90 个连续日历日起算）（L18294–18307）。

**F038** Class F Transition Period 为 **450 天**（"the 450-day Class F Transition Period"，L18833）；期间届满时，所有流通 Class F 与 Class E 将被公司无偿赎回并发生其他治理变化（L18833–18835）。

**F039** Class F Sunset 一旦触发，同样**不得延长、推迟或豁免**（L18397–18398）。

### 8.2 Continuing Founder 除名事件（自 Founder LLC 移除，取最早发生者）

**F040** 除名事件清单（六项）：(i) 辞去 Founder LLC 成员身份；(ii) 死亡或丧失行为能力；(iii) **就七位原始联席创始人各自而言**——在某次股东投票登记日，其（连同相关持有人）持有的 Class A 股份（含期权、RSU 及其他可转换证券下股份）**低于发行完成时其与相关持有人所持 Class A 股份数的 2%**；(iv) 因「cause」被移除（含 Founder LLC Agreement 中界定的特定竞争活动）；(v) 就 Class F Transition Period 开始前加入的继任成员（期间内成员除外）而言——本次发行完成的**十周年**；(vi) **就七位原始联席创始人各自而言**——开始经其他 Continuing Founders Supermajority 批准的休假（该批准不得在 Transition Period 内作出，亦不得因其本身导致 Transition Period 启动）（L18308–18341、L18842–18855）。

**F041** 除名程序：因辞职、死亡或十周年发生而**自动**生效；因丧失行为能力（incapacity）需由该创始人与其他创始人多数共同选定的合格医师认定（身体或精神障碍情形），或由其他创始人 Supermajority 认定（错误监禁、非法拘禁、俘获或拘禁情形），受影响创始人有权异议；因 cause 移除需其他创始人 Supermajority 积极认定，受影响创始人有权异议，特定 cause 类别还可补救（cure）（L18360–18382）。

**F042** 因丧失行为能力、cause 或未维持最低持股门槛而移除的，需 Founder LLC 经**其他 Continuing Founders 多数**行动事先书面通知（L18383–18387）。

**F043** 若 Continuing Founder 在发行完成后**前十年**内因死亡或丧失行为能力被移除，可接纳继任成员加入 Founder LLC，且在发行完成十周年前该继任成员计入避免触发 Class F Transition Period 所需的三名 Continuing Founders（L18388–18396）。

**F044** 在 Class F Transition Period 期间，无论距发行完成多久或移除原因如何，均可接纳一名或多名继任成员以确保有三名 Continuing Founders 任职至期间届满；**期间内的接纳不治愈触发事件、也不延长期间**（L18836–18841）。

### 8.3 日落前后的投票权与董事选免变化（Changes in Voting Power and Director Election and Removal Rights）

**F045** Class T Sunset 前：LTBT 作为 Class T 唯一持有人，原则上有权选举和罢免 Class T 董事，而 **Class T 董事构成董事会授权成员的多数**（L18409–18420）。

**F046** Class F Sunset 前：Class F 享有合计等于登记日总投票权 **50.1%** 的票数，并与 Class A 作为单一类别共同投票，选举非 Class T 董事并决定所有一般事项（L18438–18447）。

**F047** Class T Sunset 后（若 Class F 仍流通）：Class A 与 Class F 作为单一类别共同选举**全部**董事；因 Class F 恒占 50.1%，Founder LLC 能决定所有提交股东会事项的结果（L18421–18431）。

**F048** Class F Sunset 后（若 Class T 仍流通）：LTBT 继续有权选举和罢免构成董事会多数的 Class T 董事，但**不再需要遵守对 Specified Class T Director 的提名/罢免/变更指定程序**；Class A 选举和罢免其余董事并决定所有其他事项（L18448–18462）。

**F049** 若 Class T 与 Class F 均不再流通：Class A 将能决定所有提交股东会事项的结果，包括选举全部董事（L18432–18437、L18463–18469）。

## 9. 优先股（Preferred Stock，L18470–18501）

**F050** 本次发行完成后**无优先股流通**（L18470–18471）。

**F051** 董事会（经授权成员 **80%** 批准，含 0.5 向上取整规则）有权在一个或多个系列中发行优先股、确定各系列股数并固定其指定、权力、优先权与权利，**无需股东进一步投票或行动**；但 **Class F Sunset Time 之前**，未经 Founder LLC 投票或同意，董事会不得指定或发行任何系列优先股（L18472–18480）。

**F052** 董事会（80% 批准）可增减任一系列优先股股数（不得低于该系列当时流通数），无需股东行动（L18481–18483）。

**F053** 若发行带一般事项投票权的优先股，Class A 投票权将被稀释，而 **Class F 投票权仍固定为登记日总投票权的 50.1%**（L18489–18494）。

**F054** 优先股的发行可能延迟、推迟或阻止公司控制权变更，并可能对 Class A 市价及股东权利产生不利影响；**公司目前无发行任何优先股的计划**（"We have no current plan to issue any shares of preferred stock"）（L18495–18501）。

## 12. 反收购条款（Anti-Takeover Provisions，L18628–18786）

**F076** 本节条款可能延迟、推迟或阻止他人取得控制权，并部分旨在促使收购方先与董事会谈判；公司认为增强谈判保护能力的收益大于劝退收购要约的弊端（L18628–18635）。

### 12.1 特拉华法 Section 203（L18636–18664）

**F077** 公司**已选择在（Class F Sunset Time 与 Class T Sunset Time 中较晚者发生之前）不受 DGCL Section 203 约束**；修订后公司注册证书规定自该较晚时点起 Section 203 限制即适用（L18636–18641）。

**F078** Section 203 一般禁止公众特拉华公司与「interested stockholder」在后者成为 interested stockholder 的交易日起**三年**内进行「business combination」，除非：(a) 董事会在其成为 interested stockholder 前已批准；(b) 交易完成时 interested stockholder 拥有交易开始时公司流通表决股**至少 85%** 的投票权（扣除董事兼高管持股及特定员工计划持股）；或 (c) 董事会批准并经年度/特别股东大会（**非书面同意**）以**至少三分之二**未被 interested stockholder 持有的流通表决股通过（L18641–18660）。

**F079** Section 203 定义「business combination」包括合并、资产出售及其他使股东获财务利益的交易；「interested stockholder」为连同关联人持有（或三年内曾持有）公司流通表决股 **15% 以上**投票权的人士（L18661–18664）。

### 12.2 多类股结构（L18673–18684）

**F080** 在该治理结构下，公司预期 **LTBT 与 Founder LLC 将共同有能力选举董事会全部成员**，且 **Founder LLC 将有能力决定所有提交股东会一般事项的结果**（含并购等重大公司交易之股东批准）；此类交易还需董事会批准（其多数由 LTBT 选举）；除非多数 Continuing Founders 无法就 Class F 投票达成一致（届时 Class F 大体按 Class A 所投票数比例投票），Class A 持有人无论怎样投票原则上无法影响任何事项或董事选举结果（L18673–18684）。

### 12.3 分级董事会（Classified Board，L18685–18703）

**F081** **Class F Sunset Time 之前**：不设分级董事会，全体董事每年任期一届（annual terms），任期至下次年会及继任者当选合格（L18687–18691）。

**F082** **Class F Sunset Time 之后**：转为三级、规模大致相等的分级董事会，交错三年任期；届时由在任董事会将董事分配入级；若 Class T 仍流通，Class T 董事与其他董事按比例分配至各级；此后每次年会仅选一个级别；董事人数增减在三级间分配，使每级尽可能各占三分之一（L18692–18703）。

### 12.4 董事会空缺（Board Vacancies，L18704–18724）

**F083** Class T Sunset 前，仅 Class T 持有人可填补 Class T 董事空缺（受 Specified Class T Director 提名程序约束）；Class F Sunset 前，非 Class T 董事空缺由 (a) 董事会依 Founder LLC 书面推荐通知后填补，或 (b) Class A 与 Class F 共同投票/书面同意填补；Class F Sunset 后仅董事会可填补非 Class T 空缺（L18704–18713）。

**F084** Class T Sunset 前，董事会人数只能经**授权成员 80%** 批准设定（含 0.5 向上取整）；且直至 Class F Sunset 与 Class T Sunset 中较早者发生前，**授权董事总数必须为奇数**；Class T Sunset 后改为授权成员多数即可；此类条款防止股东先扩盘后填空夺board（L18713–18724）。

### 12.5 股东提案与董事提名的提前通知（L18725–18738）

**F085** 修订后章程细则规定提前通知程序（适用于 Class T/Class F 持有人以外、且非按公司注册证书或股东协议提名程序行事的股东），并规定通知形式与内容要求；未遵循程序可能导致提案或提名无效（L18725–18732）。

**F086** **NGC（董事会提名与治理委员会——原文缩写）有权就 LTBT 或 Founder LLC 的任何董事提名、对该等董事的罢免建议、以及 LTBT 受托人的任免获得 30 天事先书面通知**；NGC 可酌情豁免该通知期（L18733–18737）。

## 19. Rule 144 与 Rule 701（L19228–19261）

**F118** Rule 144（非关联人）：公司受《交易法》13 或 15(d) 报告要求 **90 天**后，非关联人且持满 **6 个月**者可出售而免于 manner-of-sale、数量限制及通知条款（仍需满足公开信息要求）；持有满 **1 年**（含非关联前手持有期）则可完全豁免 Rule 144 各项要求出售（L19229–19237）。

**F119** Rule 144（关联人）：关联人或代其出售者在禁售/锁定协议到期后，任一三个月期间可出售不超过以下较大者的股份：(a) 当时流通股本的 **1%**（发行完成后即时等于 [空白] 股）；(b) 提交 Form 144 通知前**四个日历周** Class A 平均周成交量；并受出售方式、通知及公开信息可得性约束（L19238–19253）。

**F120** Rule 701：依书面薪酬计划/合同购股且前 90 天内非关联人的股东，可依 Rule 144 出售而免于公开信息、持有期、数量限制及通知条款；关联人出售其 Rule 701 股份可免持有期要求；**所有 Rule 701 股份持有人均须待招股书日后 90 天方可依 Rule 701 出售**（L19254–19261）。

## 21. 非美国持有人的美国联邦所得税重要后果（Material U.S. Federal Income Tax Consequences to Non-U.S. Holders，L19285–19513）

**F123** 范围：仅针对本次发行取得的 Class A 之持有与处置的重大美国联邦所得税后果，基于 Code、财政部法规、行政裁定与司法判决（截至招股书日），可能追溯变更；不涉及州、地方、非美国税务或联邦非所得税（赠与/遗产税，除有限提及）；非税务建议，投资者应咨询税务顾问（L19296–19301、L19356–19361、L19510–19513）。

**F124** 明确不适用（特殊规则）的人群包括：银行/保险公司等金融机构（除下文特别规定）、RIC、REIT；受 AMT 或净投资收入 Medicare 附加税者；免税组织/政府组织；养老金/免税退休计划；CFC、PFIC 及为避税累积盈利的公司；证券经纪交易商；选用 mark-to-market 的证券交易者；持有 **5% 以上**股本者（除特别规定外）；某些美国前公民/长居居民；合伙企业等穿透实体；对冲/straddle/conversion 交易持有人；通过员工期权或薪酬取得股份者；适用 Section 451(b) 特殊会计规则者；非 Section 1221 资本资产持有者；推定出售条款适用者（L19307–19347）。

**F125** 非美国持有人定义：非穿透实体的 Class A 受益所有人，且非以下任一：美国公民或居民个人；美国或任一州（或哥伦比亚特区）法律设立的公司；收入无论来源均须缴纳美国联邦所得税的遗产；由美国法院主要监管且由美国人控制全部重大决策的信托、或已有效选择作为美国人对待的信托（L19362–19379）。

### 21.1 分配/股息（Distributions，L19380–19421）

**F126** 分配在当前或累计盈余与利润（earnings and profits）范围内构成股息；超出部分构成资本返还（return of capital），先冲减持股基数（不低于零），再视为出售/处置股票的收益（L19380–19386）。

**F127** 股息一般按 **30%** 总额预扣美国联邦预扣税，或适用税收协定更低税率；依适用财政部法规，扣缴义务人可就**整个分配的总额**预扣最高 30%，即使其中构成股息的金额较低；多扣可向 IRS 适时申报退税/抵免（L19387–19395）。

**F128** 获取协定优惠税率须向扣缴义务人提交 IRS Form W-8BEN / W-8BEN-E 或其他适当 W-8 版本（含纳税人识别号及合格证明），并按法律要求适时更新；通过金融机构或代理持股的须向代理提供文件、由其向公司或付款代理出具证明（L19396–19407）。

**F129** 与美国贸易或业务有效关联（effective connection）的股息（如协定要求，归属于美国常设机构/固定基地）一般免预扣税，须提交 Form W-8ECI；该等股息仍须计入美国所得税申报、按适用于美国人的相同税率课税（扣除特定扣除与抵免）；公司型非美国持有人还可能适用 **30%** 分支利润税（branch profits tax，或协定更低税率）（L19408–19421）。

### 21.2 处置收益（Gain on Disposition，L19422–19458）

**F130** 非美国持有人出售或以其他方式处置 Class A 一般**不**缴纳美国联邦所得税，除非：(1) 收益与其美国贸易/业务经营有效关联（协定下归属于美国常设机构/固定基地）；(2) 非居民外籍个人在处置所在日历年在美停留**合计 183 天或以上**且满足某些其他条件；或 (3) 公司构成 USRPHC（美国不动产控股公司）且（股份在成熟证券市场常规交易时）该持有人在前述期间持有 **5% 以上** Class A（L19422–19440）。

**F131** USRPHC 判定：美国不动产权益公允价值 ≥ 全球不动产权益及其他经营用资产公允价值之和的 **50%**；**公司认为其目前不是、且未来不会成为 USRPHC**（无保证）（L19441–19446）。

**F132** 上述第 (1) 种情形：净收益按常规累进税率课税，公司型持有人另可能适用 30% 分支利润税（均受协定调整）；第 (2) 种情形：按 **30%**（或协定更低税率）对处置收益课税，可用某些美国来源资本损失抵减（须适时申报美国税表）（L19447–19458）。

### 21.3 备份扣缴与信息申报（Backup Withholding and Information Reporting，L19459–19484）

**F133** 公司须每年向 IRS 申报股息金额、持有人姓名地址及预扣税额，并向持有人发送类似报告；依税收协定或其他协议，IRS 可向持有人居住国税务当局提供该等报告（L19459–19463）。

**F134** 股息及出售/处置 Class A 的款项可能适用信息申报与备份扣缴——**当前税率为 24%**——除非持有人确立豁免（如以 W-8BEN/W-8BEN-E 等证明非美国身份）；提交扣缴义务人的文件可能需在某些情形下更新（L19464–19468）。

**F135** 经由**美国境内**经纪商（美国或外国）办事处完成的出售款项一般适用信息申报与备份扣缴（除非证明非美国持有人身份并满足其他要求或确立豁免）；经由**美国境外**外国经纪商完成的交易一般不适用；但具有实质性美国所有权/经营的经纪商境外办事处交易按类似美国办事处方式处理；若公司或付款代理实际知悉或有理由知悉持有人为美国人，仍可能适用（L19469–19478）。

**F136** 备份扣缴非额外税收：纳税义务以扣缴额抵减；如导致多缴，适时向 IRS 提供所需信息后可获退税或抵免（L19481–19484）。

### 21.4 FATCA（L19485–19509）

**F137** FATCA（Code 第 1471–1474 条及其实施法规与行政指引）一般对支付给「外国金融机构」的股息、以及（受下述拟议法规约束）出售/处置 Class A 的**总价款（gross proceeds）**征收 **30%** 美国联邦预扣税——除非财政部另有规定，或该机构与美国政府签约对特定款项预扣并向美国税务机关提供其美国账户持有人（含特定权益与债务持有人、有美国所有人的非美国实体账户持有人）的实质信息，或另行确立豁免（L19485–19494）。

**F138** FATCA 亦一般对支付给「非金融外国实体（non-financial foreign entity）」的股息及（受拟议法规约束的）处置总价款征收 **30%** 预扣税——除非财政部另有规定，或该实体向扣缴义务人提供证明其直接/间接「substantial United States owners」身份及信息、证明无该等实质美国所有人、或另行确立并证明豁免（L19494–19500）。

**F139** FATCA 预扣条款**一般适用于 Class A 股息**；财政部已发布**拟议法规**规定 FATCA 预扣不适用于出售/处置 Class A 的总价款，纳税人可在最终法规发布前依赖该拟议法规；美国与居住国政府间协议（IGA）可能修改上述要求（L19500–19505）。
