## 2. 超额配售选择权（Over-Allotment Option）

- 公司将授予承销商一项期权，自本招股书日期起**30 天内**可行使，按封面所列公开发行价（扣除承销折扣与佣金）购买最多 [留空] 股额外 A 类普通股。（L19554–L19557）

## 5. 锁市协议与市场稳定协议（Lock-Up and Market Standoff Agreements）

### 5.1 董事、高管及几乎全部资本证券持有人的市场稳定协议

- 公司董事、高管及持有公司**几乎全部（substantially all）**资本股及可转换/可行权/可交换为资本股之证券的持有人，已与公司签订市场稳定协议：除若干例外，自本招股书日期起 **180 天**内，未经公司事先书面同意，不得出售、卖空、出借、授予任何购买选择权或以其他方式处置公司任何证券（含转换、行权、交换、重新分类或替换后发行或可发行的证券）。（L19594–L19599）
- 承销商要求这些市场稳定条款适用于本次发行；公司已在承销协议中同意执行这些条款及类似限制（期限至招股书日期后最多 180 天），且未经代表事先书面同意不得修改或豁免——唯一例外是为允许符合下述锁定协议条款的「Transfer」（定义见下）而作的修改或豁免。（L19600–L19606）
- 上述执行义务不适用于锁定期超出招股书日期后 180 天的股份。（L19607–L19608）

### 5.2 公司锁定期（Company Lock-Up Period）

- 公司锁定期为自招股书日期起至以下两者中较早者：（x）截至 2027 年 3 月 31 日财季（fiscal quarter ending March 31, 2027）季度财务业绩公开发布（不含"flash"数字或初步、部分业绩；该发布日称 **"Q1 Earnings Release Date"**）后第二个完整交易日东部时间上午 6:00；或（y）招股书日期后第 **180 天**（"180th Day"）交易日收盘之后即刻。（L19609–L19615）
- 锁定期内，未经代表代表承销商事前书面同意（受若干例外约束），公司不得：(a) 要约、出售、签约出售、质押、授予任何购买选择权、卖空或以其他方式直接或间接转让或处置、或向 SEC 提交/秘密递交涉及 A 类普通股或其他实质类似证券（含期权、认股权证、可转换/可交换证券，包括 Class N common stock 及因行权/转换/交换可发行的股份）的《证券法》注册声明，或公开披露任何此类要约、出售、质押、处置或申报意图；或 (b) 订立任何互换或其他全部或部分转移 A 类普通股所有权经济后果的协议（无论以股份、现金或其他方式结算），或公开披露订立此类股权互换或转移安排的意图。（L19616–L19629）

**公司锁定期不适用于以下情形（例外 (a)–(m)）**（L19630–L19677）：

- (a) 本次发行中出售的股份。（L19630）
- (b) 行使（含净行权）期权或认股权证、归属与结算（含净结算）RSU 或类似股权奖励、或证券的重新分类/交换/转换而发行普通股——均限于招股书日期已发行且本文所述者。（L19631–L19633）
- (c) 依本文所述员工福利计划向员工、高管、董事、顾问或咨询人授予或发行、或行权/结算（现金、股票或其他）期权、SAR、限制性股票、RSU、业绩股票奖励或其他股权奖励，或依本文所述员工购股计划发行普通股。（L19634–L19640）
- (d) 就员工福利计划或员工购股计划所授或将授证券向 SEC 提交一份或多份 Form S-8（或后继表格）注册声明。（L19640–L19642）
- (e) 代表股东、员工、高管或董事设立或修订 Rule 10b5-1 交易计划，但 (i) 该计划不得在公司锁定期内转让普通股（锁定协议另行允许者除外），且 (ii) 如需或自愿就计划设立/修订作出公告或申报，须声明锁定期内不得依该计划转让。（L19643–L19650）
- (f) 代表员工促进普通股出售，以满足股权奖励归属/行权/结算时应付的预扣税款。（L19651–L19653）
- (g) 任一类/系列股本相互间的交换或转换。（L19653–L19655）
- (h) 公司发行可转换票据，或依本文所述票据购买协议发行或可发行的票据转换时发行普通股或 Class N common stock。（L19655–L19657）
- (i) 因慈善捐赠或依本文所述捐赠配比计划发行普通股。（L19657–L19658）
- (j) 为行使本文所述任何注册权而秘密递交注册声明及相关准备，但该递交/准备不得导致锁定期内公开向 SEC 提交注册声明或由公司或第三方公开宣布拟注册（且公司须事先通知承销商）。（L19658–L19664）
- (k) 本文所述 Class F common stock 与 Class E common stock 的发行。（L19665）
- (l) 与本次发行同步的私募中发行普通股（本文所述）。（L19666–L19667）
- (m) 为收购任何人的股权或资产、以任何方式收购许可权、使用权、业务、财产、资产、产品、技术或人员（含承接的员工福利计划）、或涉及合资、商业关系或其他战略/合作性公司交易或联盟，而出售、交换、发行普通股或可转换/可行权/可交换证券（含期权、限制性股票、RSU、认股权证）或订立相关协议，或相关注册声明的宣布或申报。（L19668–L19677）

### 5.3 锁市协议签署主体与「Transfer」定义

- 除市场稳定协议外，**创始人、董事、高管、某些现任及前任员工与顾问、以及某些其他股东（包括本次发行前持有公司完全稀释股份（fully diluted shares）超过 0.5% 的某些股东）**已签署锁定协议，受限于与本次发行相关的 Transfer 限制。（L19678–L19681）
- 签署锁定协议的持有人合计持有本次发行前公司完全稀释股份约 **%（留空）**。（L19682–L19683）
- 锁定协议所述「普通股」指 Class A common stock 与 Class N common stock。（L19684–L19685）
- 未经代表代表承销商事前书面同意，锁定方不得（亦不得使其关联方）：(a) 要约、出售、签约出售、质押、授予任何购买期权/权利/认股权证、购买任何卖出期权或卖出合约、出借或以其他方式转让或处置任何普通股、购买普通股的期权/认股权证、或任何可转换/可交换为或代表有权收取普通股的证券（合称 "lock-up securities"，含现持有及日后取得者及因行权/转换/交换可发行股份）；(b) 从事任何旨在或合理预期会导致出售、出借、质押或其他处置、或全部或部分直接或间接转移 lock-up securities 所有权经济后果的对冲或其他交易或安排（包括卖空、买入或卖出看跌/看涨期权、远期、掉期或其他衍生交易）；(c) 就任何 lock-up securities 提出注册要求或行使注册权；(d) 以其他方式公开宣布从事上述 (a)(b)(c) 任何行动的意图。上述任何出售、出借、质押或其他处置或经济后果转移在本节中称为 **"Transfer"**。（L19685–L19706）
- 例外：若锁定方为**创始人**，且该行动已获锁定协议允许，则该创始人可在向代表及公司提前**三个营业日**书面通知后公开宣布该行动。（L19707–L19710）

### 5.4 锁定协议的转让例外（a）–（e）及附加条件

例外 (a)：锁定方转让 lock-up securities 的下列情形（L19711–L19777）：

- (i) 死亡时依遗嘱、遗嘱文件或无遗嘱继承转让。（L19712）
- (ii) 自然人转让给其直系亲属成员、被扶养人、或为锁定方/其直系亲属/被扶养人直接或间接受益的信托、公司、合伙、有限责任公司或其他实体；创始人的情形可转让给任何慈善组织；锁定方为信托时可转给信托设立人、受托人或受益人或其遗产。（L19713–L19718）
- (iii) 转让给锁定方及其直系亲属为全部已发行股权或类似权益法定与受益拥有人的公司、合伙、有限责任公司或其他实体。（L19718–L19721）
- (iv) 转让给上述 (a)(i)–(iii) 允许受让之人或实体的代名人或保管人。（L19721–L19722）
- (v) 锁定方为公司/合伙/有限责任公司/信托或其他商业实体时：(A) 转让给其关联方、或与其存在控制/管理/顾问/共同控制关系的投资基金或其他实体；或 (B) 作为向其股东、现任或前任合伙人、成员、管理人、受益人或其他权益持有人（或其遗产）的分配、转让或其他处置的一部分。（L19722–L19731）
- (vi) 依法律实施转让，如合格家庭关系令、离婚协议、离婚判决、分居协议或法院或监管机构的其他命令。（L19731–L19732）
- (vii) 公司或其子公司的员工或服务提供者因死亡、残疾或雇佣终止（含自愿辞职）而向公司转让。（L19732–L19735）
- (viii) 锁定方非公司高管或董事时：转让其 (A) 在本次发行中自承销商取得、或 (B) 在本次发行交割日后公开市场交易中取得的普通股。（L19735–L19737）
- (ix) 锁定方依本次发行承销协议向承销商出售 A 类普通股。（L19737–L19739）
- (x) 为满足 RSU/期权/认股权证/交换/转换权等归属、结算或行权（含"净"或"无现金"方式，且限于适用锁定期内已归属、将归属或预定到期或自动归属者）的行权价或税负（含预扣与预估税负）或汇款义务而向公司转让，或可转换证券转换相关转让——均须依本文所述股权激励计划或可转换/可交换证券条款，且受让证券仍须受锁定协议约束。（L19739–L19751）
- (xi) 锁定方为创始人、董事、高管或现任/前任员工或顾问时，以"sell to cover"或类似公开市场交易筹资支付行权价或税负——须依本文所述计划，且处置后保留的证券仍须受锁定协议约束。（L19752–L19762）
- (xii) 向第三方受质人于善意交易中质押，作为该第三方（或其关联方/指定人）与锁定方及其关联方之间借贷或类似融资安排的担保；创始人可为其遗产规划工具；质权人依约执行担保权益而出售/转让/划转/处置 lock-up securities 亦被允许——前提是该安排非对冲交易/安排且非规避锁定安排的计划的一部分。（L19763–L19773）
- (xiii) 一项或多项善意赠与或慈善捐赠（现任/前任员工或顾问中非创始人、董事或高管者除外）；创始人可为善意遗产规划目的转让。（L19773–L19777）

- (A) 例外 (a)(i)–(v) 及仅涉善意赠与/慈善捐赠的 (xiii)：转让或分配不得涉及有偿处置（disposition for value）。（L19778–L19780）
