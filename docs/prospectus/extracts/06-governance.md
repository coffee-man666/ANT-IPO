## 1. 章节总纲：新型资本与治理结构（L14576–14584）

- **核心定位（原文，L14576–14577）**："Our novel capital and corporate governance structure has been carefully designed and differs significantly from that of other public companies."（我们新颖的资本与公司治理结构经过精心设计，与其他上市公司显著不同。）【F1】
- 公司使命表述（原文，L14577–14578）："We strive to help bring humanity safely into an era where transformative AI exerts tremendous and potentially decisive influence over a broad range of human undertakings."（努力帮助人类安全进入一个变革性 AI 对广泛人类事业施加巨大甚至可能决定性影响的时代。）【F2】
- PBC 结构赋予董事会必要的裁量空间，以平衡三类利益：股东的经济利益（pecuniary interests）、受公司行为重大影响者的最佳利益（best interests of those materially affected by our conduct）、公司宗旨（Company Purpose）（L14578–14580）。【F3】
- 一个"财务上无利害关系的 LTBT"（a financially disinterested LTBT）通常有权选举和罢免董事会**法定成员的多数**，其设计目的在于为恰当把握上述平衡提供激励与洞察（L14581–14583）。【F4】
- 公司认为七位联合创始人特别适合充当使命的守护者（stewards of our mission）（L14583–14584）。【F5】

## 2. 公益利益公司（Public Benefit Corporation，PBC）（L14585–14626）

- 注册地与性质：根据特拉华州法律注册为 **PBC**，这一结构支撑其对 AI 安全与责任的承诺（L14586–14587）。PBC 是旨在产生公共利益、以负责任和可持续方式运营的一类公司（L14587–14588）。【F6】
- 三重平衡义务（原文，L14588–14589）："As a PBC, we are required to balance (i) the pecuniary interests of our stockholders, (ii) the best interests of those materially affected by our conduct, and (iii) the Company Purpose."（作为 PBC，我们必须平衡：(i) 股东的经济利益，(ii) 受我们行为重大影响者的最佳利益，(iii) 公司宗旨。）这要求董事会在股东经济利益之外同时权衡决策的长期与短期外部性等因素（L14590–14591）。【F7】
- 公司迄今发现：AI 的安全与社会效益、对各关键利益相关方群体最佳利益的考量，总体上与其长期商业成功及股东的长期货币利益**相一致**（L14591–14593）。【F8】
- 风险提示：作为 PBC，公司可能做出其认为恰当平衡三类利益、但**负面冲击短/中/长期业务表现或 Class A 普通股股价**的决策（L14594–14597）。【F9】
- 法律不确定性：解释特拉华州 PBC 平衡义务的**司法判例有限**，法院如何看待董事会对这些潜在竞争性利益的平衡存在不确定性（L14597–14599；并交叉引用两条 Risk Factors，L14599–14607）。【F10】
- **五大使命支柱（five mission pillars）**——衡量公共利益表现时董事会将考虑的目标（L14608–14611）：【F11】
  1. AI 安全的技术问题得到解决（the technical problems of AI safety are solved）；
  2. AI 安全成为以法律为支撑的普遍实践（AI safety is a universal practice backstopped by law）；
  3. AI 强化民主与全球稳定（AI strengthens democracy and global stability）；
  4. AI 扩大繁荣与人类繁荣（AI expands prosperity and human flourishing）；
  5. AI 的利益被所有人共享（AI's benefits are shared by everyone）。
- 公司还可能处理客户、合作伙伴、员工及其他不时识别出的利益相关方的额外利益（L14612–14614）。【F12】
- **不采用第三方标准**：修订重述的公司注册证书与章程均不要求以客观第三方标准衡量公共利益表现；由董事会负责建立并监督衡量标准（L14615–14617）。公司目前预期这些目标与标准将为**定性**（qualitative）性质，并可能随业务增长与影响理解深化而演变（L14618–14620）。【F13】
- 双年报义务：按 DGCL 第 366(b) 条要求，公司将于**不少于每两年**向股东提供一份评估公司宗旨推进情况及受其行为重大影响者最佳利益的声明（statement），说明目标、标准与已采取的行动；计划通过公司网站向股东和公众公开（L14621–14624）。【F14】
- 公司还预期通过继续在网站发布循证研究（evidence-based research）展示进展（L14625–14626）。【F15】

## 3. 长期利益信托（Long-Term Benefit Trust, LTBT）（L14629–14647）

### 3.1 设立、性质与目的

- 设立 LTBT 的目的是确保公司以负责任地平衡 PBC 三重目标的方式被管理：(i) 股东经济利益、(ii) 受影响者最佳利益、(iii) 公司宗旨（L14630–14632）。【F16】
- 法律形式：LTBT 为特拉华州法律下的普通法 **"非慈善目的信托"（common law "noncharitable purpose trust"）**，受《长期利益信托修订重述信托协议》（Long-Term Benefit Trust Amended and Restated Trust Agreement，"Trust Agreement"）管辖（L14632–14634）。【F17】
- 定位：一个由具备 **AI 安全、国家安全、公共政策、社会企业**专长的受托人组成的独立机构（L14634–14635）。【F18】
- 独立性设计：LTBT 的安排旨在**最小化 LTBT 及受托人对公司财务表现的敞口**（minimize the LTBT's and the Trustees' exposure to our financial performance），并赋予受托人充分独立性（L14635–14637）。【F19】

### 3.2 Class T 普通股与 LTBT 的权力边界

- 通过特殊类别普通股 **Class T common stock**，LTBT 通常有权选举和罢免 **Class T directors**——他们合计构成董事会法定成员的**多数**（a majority of the authorized members of our board of directors）（L14638–14640）。【F20】
- **Class T 普通股无任何经济权利（has no economic rights）**（L14640）。【F21】
- 权力边界（原文，L14641–14645）：公司业务与事务的决策由董事会作出；尽管 LTBT 通过选举/罢免 Class T 董事对董事会有重大影响力，**"neither the LTBT nor the Trustees have decision-making authority in the day-to-day management or strategy setting of the company"**（LTBT 及受托人对公司日常管理或战略制定均无决策权）。LTBT 的角色是遴选具备能力恰当平衡 PBC 三重目标的董事，并通过建议和指导（advice and guidance）支持管理层决策。【F22】
- 特定重大行动——合并（merger）、联合（consolidation）、出售全部或实质性全部资产——依特拉华州法律须经董事会批准，而董事会多数由 LTBT 选出（L14645–14647）。【F23】

## 4. 董事的选举与罢免（Election and Removal of Directors）（L14648–14675）

- LTBT 作为 Class T 普通股唯一持有人，通常有权选举和罢免 Class T 董事（合计构成董事会法定成员多数）（L14649–14650）。【F24】
- Class T 普通股**不参与**选举/罢免由 Class A 与 Class F 持有人选出的董事——后者仅由 Class A 与 Class F 普通股（共同投票，voting together）选举或罢免（L14651–14653）。【F25】
- 现任及发行完成后 Class T 董事名单见 "Management—Board of Directors"（L14653–14655）。【F26】
- **NGC 通知期**：提名或罢免董事前，提名方须向公司 NGC（Nominating and Governance Committee，提名与治理委员会）提供**至少 30 天**通知，该通知期可由 NGC 自行决定放弃（waivable by our NGC in its discretion）（L14656–14657）。【F27】
- 发行完成后 NGC 构成：**1 名 Class T 董事 + 2 名非 Class T 董事**，以多数决行事（L14658–14660）。【F28】
- **Specified Class T Director（指定 Class T 董事席）机制**（L14661–14669）：对其中一个 Class T 董事席位（"Specified Class T Director"），LTBT 提名该董事、无因罢免该董事或变更被指定为 Specified Class T Director 的人选，均须 **NGC 同意（concurrence）**。【F29】
  - 若 NGC 在收到通知后 **15 天内**未表示同意，事项将提交 **Class E 普通股持有人表决**——除非 LTBT 选择撤回通知（L14663–14665）。【F30】
  - 交由 Class E 表决时，通过 LTBT 提案须获得 Class E 普通股**所投投票的多数**（a majority of the votes cast），法定人数要求为**已发行 Class E 普通股的多数**（L14665–14667）。【F31】
  - LTBT 可在表决前**随时撤回**任何提名、罢免或变更指定的通知（L14668）。【F32】
- **有因罢免（removal for cause）**：任何 Class T 董事（含 Specified Class T Director）均可因故被罢免——依特拉华州法律认定——**无需** NGC 同意或 Class E 持有人批准；但 LTBT 与 Founder LLC 各自同意，在实施任何有因罢免前向**另一方及 NGC 提前 30 个日历日**通知（L14669–14675）。【F33】

## 5. LTBT 与 Class T 普通股条款的修改（Trust Amendment Threshold）（L14678–14705）

LTBT 条款及 Class T 普通股权利可按以下任一门槛（合称 **"Trust Amendment Threshold"**）修改（L14679–14680）：

- **情形一：受托人投赞成票时**（L14681–14684）：须 **董事会法定成员的 80%** 与 **在任受托人的 80%** 批准（两者均四舍五入至最接近整数，恰为 0.5 时向上取整）。【F34】
- **情形二：Class F 普通股仍发行在外且受托人不投赞成票时**（L14685–14699）：
  - **截至本次发行完成三周年前**（until the third anniversary of the completion of this offering），须同时满足：(i) Class F 普通股依据 **Continuing Founders 一致同意**行事，(ii) Class E 普通股**所投投票的多数**批准（法定人数为**已发行 Class E 的 40%**），(iii) 已发行 Class A 普通股**所投投票的多数**批准（法定人数为已发行 Class A 的多数）（L14689–14693）；【F35】
  - **任何时间**（at any time），须同时满足：(i) Class F 普通股按 **66 2/3% Continuing Founders** 的决定行事（向上取整至整数），(ii) **Class E 所投投票的 75%** 批准（法定人数为已发行 Class E 的多数），(iii) Class A 所投投票的多数批准（法定人数为已发行 Class A 的多数）（L14694–14699）。【F36】
- **情形三：无 Class F 发行在外且受托人不投赞成票时**：须**已发行 Class A 普通股的 85%** 批准（L14700–14702）。【F37】
- **Class T 可被无偿赎回**：公司可按上述修改门槛（同 Trust Amendment Threshold）批准后，**以零对价（for no consideration）赎回 Class T 普通股**（L14703–14705）。【F38】

### 8.2 Class F 普通股与 Founder LLC 核心机制

- 发行时点与载体：紧接本次发行完成前，公司向 **Founder LLC** 发行**一股（a single share）Class F 普通股**；Founder LLC 为一家有限责任公司，七位联合创始人初始为其唯一成员（sole members），由其成员管理（managed by its members）（L14824–14827）。【F63】
- **投票权（原文，L14827–14829）**：Class F 普通股就**提交股东一般表决的事项**（包括选举 Class T 董事以外的董事）享有**合计等于全部已发行股本总投票权 50.1%** 的票数（as of the applicable record date）。【F64】
- 投票决定机制：Class F 由 Founder LLC 依 **Founder LLC Agreement** 投票；一般而言按 Founder LLC **有权投票成员的多数**意见投票；初始唯一成员为七位联合创始人（L14831–14833）。【F65】
- **继承成员（successor member）**：联合创始人丧失行为能力或死亡时，可接纳继承成员进入 Founder LLC，**直至本次发行完成十周年**（until the tenth anniversary of the completion of this offering）（L14834–14835）。【F66】
- **"Continuing Founders"定义**：七位联合创始人及 Founder LLC 中的任何继承成员（L14835–14836）。【F67】
- **脚注 13（Benjamin Mann，L14853–14858）**：Benjamin Mann 自 2021 年 1 月创立以来即是 Anthropic 不可或缺的一部分，常被称为联合创始人；**但他不是 Founder LLC 成员，也不是发行完成时的 Continuing Founder，因此不参与决定 Class F 投票**；除该段所述外，招股书其他处对"co-founders"的引用均不含 Mr. Mann。【F68】

### 8.3 Class F 过渡期（Class F Transition Period）与日落

- **触发条件**：当 Continuing Founders 人数（不含"Non-Qualifying Member"继承成员）**少于 3 名且持续 90 个连续日历日**时，启动 **450 天过渡期**（"Class F Transition Period"）（L14837–14839）。【F69】
- 后果：过渡期届满时，**届时已发行在外的全部 Class F 与 Class E 普通股将被公司无偿（for no consideration）赎回**，并发生若干其他治理变更（L14839–14841）。【F70】
- 过渡期内的继承成员补位：无论发行完成后经过多长时间或导致 Continuing Founder 被移除的情形如何，过渡期内均可接纳一名或多名继承成员，以确保有 **3 名 Continuing Founders** 任职至过渡期结束；但过渡期内的补位**不治愈**触发事件、也**不延长**过渡期（L14842–14847）。【F71】

### 8.4 Continuing Founder 的除名事件（L14849–14870）

Continuing Founder 将在下列**最早发生**事件时被移出 Founder LLC：

1. 该成员**辞去** Founder LLC 成员身份（L14849–14850）；
2. 该成员**死亡或丧失行为能力**（L14850–14851）；
3. 对七位原始创始人各自而言：在股东表决的任何记录日，其（连同其关联持有人）**持有的 Class A 普通股（含期权、RSU 及其他可转换证券对应股份）低于发行完成时该创始人及其关联持有人所持 Class A 股份的至少 2%**（L14851–14853, L14861–14863）；
4. 该成员因**"cause"（因故）被移除**——Founder LLC Agreement 所定义的 cause 包括其中描述的特定竞争性活动（specified competitive activities）（L14863–14865）；
5. 对过渡期启动前接纳的继承成员（过渡期内成员除外）：**本次发行完成十周年**（L14865–14867）；
6. 对七位原始创始人各自而言：**经其他 Continuing Founders 超多数（Supermajority）批准的休假（leave of absence）开始**——过渡期内不得批准休假，且若批假本身会导致过渡期启动则不得批准（L14867–14870）。

【F72】

### 8.5 投票细则

- 每名 Continuing Founder 在决定 Class F 投票时**各享 1 票**（L14871）。【F73】
- **僵局规则**：若 Continuing Founders 多数无法就 Class F 投票达成一致，则 Class F 将**按 Class A 普通股就该事项所投投票按比例**投票（法定人数为已发行 Class A 的多数）（L14872–14874）。【F74】
- **更高门槛事项**：就某些事项，仅当**更高比例**的 Continuing Founders 同意时 Class F 才投"赞成"票；未达更高门槛则投"反对"票（细节交叉引用 "Description of Capital Stock—Class F Common Stock Voting Mechanics"）（L14875–14877）。【F75】
- Founder LLC Agreement **不约束**创始人或其关联持有人自持 Class A 股份的投票——每人可自行裁量投票，无论 Founder LLC 如何投 Class F（L14879–14882）。【F76】
- **反稀释**：未来发行股本（融资、并购、员工激励等）造成的经济或投票稀释**不影响** Class F 的投票权（L14883–14885）。【F77】
- 由此，Founder LLC 可决定所有提交股东一般表决事项的结果，包括选举非 LTBT 选出的董事、公司组织文件的某些修订，及股东对任何合并、联合、出售实质性全部资产或其他需股东批准的重大公司交易的批准（L14885–14889）。【F78】

## 13. 日落条款（Sunset Provisions）——双栏对照表全文抄录（L15034–15259）

原表为 "Class T Sunset Time" 与 "Class F Sunset Time" 双栏对照，逐格抄录如下。

### 13.1 触发（Trigger）（L15035–15149）

**Class T Sunset Time（Class T 日落时点）**：
- 发生于**无 Class T 普通股流通在外**之时，包括因 Class T 被赎回、或修订 Class T 权利使之消灭（两者均须达到 Trust Amendment Threshold 的人数批准）（L15038–15044）。
- Trust Amendment Threshold 可通过（与第 5 节一致的复述，L15045–15141）：
  - 受托人赞成时：董事会法定成员 80% + 在任受托人 80%（四舍五入至整数，恰 0.5 向上）（L15047–15053）；
  - Class F 在外且受托人不赞成时：截至发行完成三周年前——Class F 依 Continuing Founders 一致同意 + Class E 多数（法定人数 40% 已发行 Class E）+ Class A 多数（法定人数多数）（L15058–15069）；或任何时间——Class F 依 66 2/3% Continuing Founders 决定 + Class E 75%（法定人数多数）+ Class A 多数（法定人数多数）（L15070–15081）；
  - 无 Class F 在外且受托人不赞成时：已发行 Class A 的 85%（L15136–15141）。
- **不随时间流逝或特定事件自动发生**：任何导致 Class T Sunset Time 的行动均须达到 Trust Amendment Threshold 的批准（L15142–15147）。
- 一旦触发，**不可延长、迟延或豁免**（not subject to extension, delay or waiver）（L15148–15149）。

**Class F Sunset Time（Class F 日落时点）**：
- 发生于以下**较早者**：(i) 无 Class F 流通在外之时——包括 **Continuing Founders 超多数（Supermajority）同意的 Class F 赎回**或 **Founder LLC 解散**；(ii) **Class F Transition Period 届满**（L15082–15091）。
- Class F Transition Period 启动：Continuing Founders（不含 "Non-Qualifying Member" 继承成员）**少于 3 名持续 90 个连续日历日**（L15091–15097）。
- Continuing Founder 除名事件（与第 8.4 节一致的复述，L15098–15131）：(i) 辞职；(ii) 死亡或丧失行为能力；(iii) 原始创始人持有 Class A（含期权/RSU/可转换证券）低于发行完成时其及关联持有人所持的至少 2%；(iv) 因 "cause"（含特定竞争性活动）被移除；(v) 过渡期前接纳的继承成员（过渡期内成员除外）——发行完成十周年；(vi) 原始创始人经其他 Continuing Founders 超多数批准的休假开始（过渡期内不得批准，批假本身会触发过渡期的亦不得批准）。
- 除名的认定机制（L15150–15177）：
  - 因**辞职、死亡或发行完成十周年**到达而除名的——**自动发生**，无需他人认定（L15150–15154）；
  - 因**丧失行为能力**——由受影响 Continuing Founder 与其他 Continuing Founders 多数共同选定的合格医师认定（身体或精神障碍情形）；或由其他 Continuing Founders 超多数认定（ wrongful imprisonment、非法拘禁、俘获或拘禁情形）；受影响成员有权 contest（L15154–15165）；
  - 因**cause**——须其他 Continuing Founders 超多数的肯定认定（affirmative determination），受影响成员有权 contest，或就特定类别的 cause 有权补救（cure）（L15165–15172）；
  - 因**无行为能力、cause 或未维持最低持股门槛**的除名，须 Founder LLC 经其他 Continuing Founders 多数行动**事先书面通知**（L15173–15177）。
- **十年内的继承**：若 Continuing Founder 在发行完成后**前十年**内因死亡或无行为能力被除名，可接纳继承成员进入 Founder LLC，该成员计入避免触发 Class F Transition Period 所需的 3 名 Continuing Founders——直至发行完成十周年（L15178–15186）。
- Class F Sunset Time 一旦触发，**不可延长、迟延或豁免**（L15187–15188）。

|---|---|---|
