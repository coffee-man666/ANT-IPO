- 现行投票协议将在本次发行中终止；现任董事任期至下届年会及继任者当选合格，或直至其更早死亡、辞职或被撤换（L15439-15442）。

### 2.2 IPO 后董事会构成（L15443-15458）
- 发行完成后董事会将由 **7 名授权董事**组成，选举方式（L15443-15444）：
  - Class T 普通股持有人（LTBT）通常有权选举和撤换 **4 名 Class T 董事**；初始 Class T 董事为 Hastings、Narasimhan、Liddell 及一个空缺席位（one vacancy）；Liddell 担任 Specified Class T Director（L15446-15453）。
  - Class F 与 Class A 普通股持有人作为一个单一类别共同投票，有权选举和撤换其余 **3 名董事**，初始为 Dr. Amodei、Ms. Amodei、Ms. Razavi（L15455-15458）。

### 2.3 董事任期（Director Terms）（L15461-15485）
- 新注册证书规定：Class F Sunset Time 之前不设分类董事会（classified board），全部董事任期一年（年度任期），任期至下届年会及继任者当选合格或更早死亡/辞职/撤换（L15462-15466）。
- Class F Sunset Time 之后，董事会转为三类别（约等规模）分类董事会，交错三年任期；届时 Class T 董事与其他董事将按比例分配至各类别（若 Class T 仍流通）；每年仅改选一个类别（L15467-15483）。
- 无论由何类别股份选举，董事任职届数无上限（"there is no limit to the number of terms a director may serve"，L15484-15485）。

### 2.4 股东会议与书面同意（L15486-15496）
- 新注册证书规定：只要 Class F 或 Class T 普通股仍流通，股东可就特定事项以书面同意（written consent）行事，包括选举或撤换董事的任何行动（L15487-15492）。
- 公司仍将按纳斯达克全球精选市场上市标准举行年度股东大会，并就相关事项（包括选举非 Class T 董事）向 Class A 持有人征集表决（L15492-15496）。

### 2.5 董事会领导结构（Board Leadership）（L15497-15510）

### 2.6 董事独立性与受控公司豁免（L15511-15547）
- 董事会认定 Hastings、Liddell、Narasimhan、Razavi 四人均符合纳斯达克全球精选市场上市标准下"独立"（independent）定义（L15512-15517）。
- 公司因 LTBT 作为 Class T 唯一持有人通常有权选举董事会授权成员的多数，而被视为纳斯达克公司治理要求下的**"受控公司"（controlled company）**（L15522-15524）。
- 受控公司可选择不遵守的治理要求包括：董事会多数为独立董事、提名与公司治理委员会（NGC）全部由独立董事组成并有书面章程、薪酬委员会全部由独立董事组成并有书面章程（L15526-15538）。
- 公司声明不打算依赖该豁免，**唯独 NGC 除外**（NGC 不会全部由独立董事组成）；董事会目前独立董事占多数，审计与薪酬委员会目前全部由独立董事组成；若不再为受控公司且 Class A 继续上市，须在过渡期内使 NGC 全部由独立董事组成（L15541-15547）。

## 七、责任限制与董事高管赔偿（Limitation of Liability and Indemnification of Officers and Directors）（L17447-17515）

- 发行前将采纳的修订重述注册证书将在 DGCL 允许的最大范围内限制董事及**特定高管**（certain officers）的金钱损害赔偿责任；例外包括：违反忠实义务、非善意或涉及故意不当/明知违法的行为、董事非法分红或非法回购/赎回（DGCL Section 174）、获取不当个人利益的交易、高管方面由公司或以公司名义提起的派生诉讼（any action by or in the right of the corporation）（L17448-17464）。
- 修订重述章程将在法律允许的最大范围内对董事、高管（及可扩及员工/代理人）因任职或应公司要求任职而涉诉提供赔偿，并须预付（advance）董事/高管的抗辩费用（受有限例外约束）（L17470-17482）。
- 公司已签/将签的与每位董事及高管的赔偿协议可能比 DGCL 具体条文更宽泛，要求赔偿并预付调查/抗辩费用；公司认为此类协议对吸引合格人员必要（L17483-17489）。
- 风险提示：上述责任限制与赔偿条款可能抑制股东诉讼与派生诉讼；公司已投保董监高责任险（D&O insurance），覆盖违反信义义务或其他不当行为索赔（含上市公司证券事项）及公司依赔偿义务支付的款项（L17490-17507）。
- 部分非雇员董事可能通过其雇主获得对其董事职务责任的保险或赔偿（L17508-17509）。
- 承销协议将规定承销商对公司及高管董事的某些责任提供赔偿（L17510-17511）。

- 特别地，依据特拉华州法律与公司注册证书，若无利益冲突，**未能满足 PBC（公益公司）地位相关的平衡义务（balancing obligations），不构成高管董事免责、费用垫付与赔偿权利下的"非善意行为"或违反忠实义务**（L17498-17502）。
