## 招股书要点速览（截至 2026/9/30，摘自第一部分）

- **公司**：2021 年创立的 AI 研究实验室，特拉华州注册的公共利益公司（PBC）；产品为 Claude（模型 + 平台 + 应用）。
- **故事线**：押注"认知工作"市场 → 产品形态是"虚拟协作者"（Claude Code + Claude Cowork）→ 终极愿景"数据中心里的天才之国"。
- **关键指标**：NRR 约 900%；人均 TTM 收入 $660 万；累计融资 $1,411 亿；算力承诺执行期排到 2045 年。
- **治理结构（最特殊处）**：五类股票，经济权利与治理权利彻底拆分；T 类（1 股）选董事会多数席位，F 类（1 股）锁定一般事项 50.1% 投票权；公众投资者持有的是无控制权的经济股，公司为纳斯达克"受控公司"。
- **公共利益绑定**：5% 完全稀释股份注入 Anthropic 公共利益基金；七位创始人各承诺个人股权的 80% 用于慈善。
- **自述主要风险**：模型竞争力掉队、算力获取受限、客户与渠道高度集中、与云服务商的利益冲突、AI 责任与监管、增长不可外推、PBC 三方平衡义务与股东财务利益的潜在冲突。
