# private/ —— L2 受限轨道

本目录已被 git 忽略（见 `.gitignore` 与 `SECURITY.md`），是仓库中**唯一**存放受限内容的地方。
本 README 是目录中唯一被跟踪的文件（作为路标）。

## 该放这里的内容

项目定义的受限内容——**清单见同目录 `classification.md`（本地文件，不入库）**。

## 规则

1. 永不 `git add`（目录已忽略；即使 `add -f`，pre-commit 钩子也会拦截）；
2. 永不把这里的内容粘贴进任何对外文稿（发布门会拦截）；
3. 文件首行写标记 `<!-- data-class: restricted -->` —— 万一被移动出本目录，
   扫描器会将其拦下（第二道防线）。
